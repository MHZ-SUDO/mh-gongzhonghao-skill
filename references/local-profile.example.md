# 本地用户配置示例

复制为同目录的 `local-profile.md` 后填写自己的已确认信息；该文件不上传GitHub。它仅提供默认值，不授予任何当次发表权限。

- 公众号：填写真实账号名称，写操作前核对当前后台。
- 合集：填写该系列实际合集；没有时注明无。
- 原创作者：填写用户确认的作者；仅在内容权属明确时声明原创。
- 工作目录：本机本期目录，使用实际存在的绝对路径。
- Python、FFmpeg、浏览器桥接：记录可复用路径，使用前检查。
- 系列风格：可沿用series-profile.md，也可填写本系列自己的选择。
- 通知与定时：默认均关闭；其他设置按当次要求。

可补充先前已确认的素材命名和操作记录线索。不要放密码、Cookie、登录token或验证码。
